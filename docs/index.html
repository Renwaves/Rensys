1. Quick start

You can run a first estimate in a few steps. For a more meaningful result, set the location and review the system assumptions before running the calculation.

Choose a location. Enter a city or address and select Search, or use Use my location if your browser allows location access. Wait for the solar data status to update.
Check the system size. Set the PV system's nominal peak power in kWp. Use the intended DC module capacity, not the building's energy consumption.
Set the array and equipment. Choose module technology, tilt, azimuth, and inverter efficiency. If you know the site's annual GHI from a reliable source, check that value too.
Run the simulation. Select Run Simulation. Review annual yield, average daily yield, performance ratio, the monthly energy chart, and the calculation log.
Compare scenarios carefully. Change one input at a time to see how the estimate responds. Keep the location and other inputs the same when comparing options.
Tip: If you search for a location, Rensys uses the returned coordinates to load solar climatology and sets an estimated tilt based on latitude. Review these values before running the simulation.

2. Location and solar data

City or address

Enter a recognizable place name. Rensys uses the Open-Meteo geocoding service to find a matching location, then requests long-term average solar irradiance from NASA POWER for those coordinates. The first geocoding match is used, so check the displayed location status and search again if the result is not the intended site.

Use my location

This option asks the browser for your device's location. Allow the request if you want to use it; otherwise, enter a city or address manually. Location services and solar-data requests require an internet connection.

Global horizontal irradiance (GHI)

GHI is the solar energy received on a horizontal surface over a period. In Rensys, it is entered as an annual value in kWh/m²/year. A location search populates this input from NASA POWER's climatological daily data, aggregated to an annual estimate and rounded to the nearest 25 kWh/m²/year.

Important: If you do not select a location, the simulator uses a fallback latitude and a default monthly distribution. The displayed default GHI is not a verified value for your actual site. Select a location or enter a defensible annual GHI value before relying on the estimate.

System peak power

Capacity scales the annual yield estimate. If all other inputs remain unchanged, doubling Pnom doubles the calculated annual energy.

Module technology

The current model uses a factor of 1.03 for monocrystalline PERC, 1.00 for polycrystalline silicon, and 0.98 for CdTe. Treat this as a simplified assumption, not a universal ranking of module performance.

Tilt and azimuth

The model applies a simplified orientation adjustment relative to its latitude-based tilt estimate. It does not perform a full plane-of-array irradiance calculation, so use these controls for screening rather than detailed optimization.

Inverter efficiency

Efficiency adjusts the simplified performance-ratio estimate. Real inverter performance varies with load, temperature, voltage, and operating conditions, which are not separately simulated here.

4. Understanding the results

Annual Yield (kWh/year)

The estimated total electrical energy produced over a year. It depends on system capacity, annual GHI, the orientation adjustment, and the simplified performance ratio.

Average Daily Yield (kWh/day)

Annual yield divided by 365. It is a yearly average, not a promise that the system will produce the same amount every day. Seasonal weather and daylight vary.

Performance Ratio (%)

A simplified model indicator representing the assumed share of solar resource converted into useful system output after modeled losses. It is not a measured value from an installed system.

Monthly Energy Production Profile

A bar chart allocating the annual estimate across months. After a location search, the distribution is based on the location's NASA POWER climatology; without a selected location, a generic default profile is used.

How to read the terminal log

The log records the simulation event and reports the system size, selected module technology, and calculated annual yield. It is a simple activity log, not a detailed engineering report or an error audit.

5. How the estimate works

Rensys v1.1 uses a compact, deterministic screening calculation. Understanding the simplified method helps you judge when it is appropriate.

Orientation factor
max(0.70, 1 − |tilt − estimated optimum tilt| × 0.002 − |azimuth| × 0.0008)

Performance ratio
clamp(0.80 × technology factor × (inverter efficiency / 0.975), 0.65, 0.90)

Estimated specific yield
annual GHI × orientation factor × performance ratio

Estimated annual yield
system peak power (kWp) × specific yield (kWh/kWp/year)

The estimated optimum tilt is calculated from latitude using a rule of thumb, capped at 60°. After a location search, monthly shares are derived from NASA POWER's climatological monthly irradiance; otherwise, Rensys uses a generic preset distribution.

Scope and limitations: The current calculator does not separately simulate shading, soiling, hourly weather, snow, degradation, temperature profiles, cable losses, mismatch, string sizing, or a detailed inverter model. Azimuth is simplified and does not distinguish east from west. Results are for early-stage screening and should not be used alone for permits, financing, guarantees, or final system design.

6. Troubleshooting

Location search does not find my site

Try a nearby city, include the region or country, and confirm you have an internet connection. The geocoder uses the first returned match, so a more specific search may help.

Solar data fails to load

Retry after checking your connection. The solar-data service may be temporarily unavailable. You can enter a known annual GHI value manually, within the control's supported range.

The result seems unexpectedly high or low

Check the location, annual GHI, system capacity, tilt, azimuth, module technology, and inverter efficiency. Make sure the GHI value is annual kWh/m²/year—not a daily value or monthly total. Remember that this model is simplified and does not represent every site-specific loss.

The monthly chart looks generic

If no location has been loaded, Rensys uses a default monthly distribution. Search for a location to replace it with the solar climatology returned for that point.

7. Frequently asked questions

Is Rensys free to use?

Yes. Rensys is a free, browser-based PV yield estimator.

Does Rensys save my inputs?

The current calculator does not implement saving a project or exporting a report. Location searches send the search query to Open-Meteo and solar-data requests to NASA POWER.

Can I use the result as a guaranteed energy forecast?

No. Treat it as an early estimate. A detailed design should use project-specific weather data, shading analysis, equipment specifications, and a more complete loss model.

Why does a location search change the tilt?

Rensys calculates a starting tilt from the latitude of the selected location. You can then adjust it to reflect the planned installation.

What does 0° azimuth mean?

In Rensys, 0° means the array faces the equator: generally south in the Northern Hemisphere and north in the Southern Hemisphere. The current simplified model only uses the magnitude of azimuth, not east/west direction.
